# Seguridad de MiS²oles

## Cómo avisar de una vulnerabilidad
Usa **«Report a vulnerability»** en la pestaña *Security* de este repositorio (aviso privado de GitHub). No abras un *issue* público ni pongas datos de otras personas.

Incluye qué pasa, cómo reproducirlo y qué podría hacer alguien con ello. Prueba solo con tu propia cuenta y datos inventados: no accedas a datos ajenos ni hagas pruebas de carga o denegación de servicio.

Respondemos en cuanto podemos (proyecto pequeño, en beta). Si es válido, lo corregimos antes de hacerlo público.

## Alcance
La app (`index.html`), la landing (`inicio/`), la página legal, las funciones y reglas de la base de datos (`supabase/`) y el respaldo (`respaldo/`).

## Reporting a vulnerability (English)
Use **"Report a vulnerability"** on this repository's *Security* tab. Please don't open a public issue, only test with your own account and made-up data, and don't run load or denial-of-service tests.
